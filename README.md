# 🛠️ ClearLens - Admin Panel

ClearLens Admin Panel is a **dashboard for managing the spectacles e-commerce platform**, built with **React**, **Tailwind CSS**, and **Axios** for API handling. It includes **JWT authentication** for secure access.

## Features

**Admin Dashboard** - Overview of sales, users, and orders  
**Product Management** - Add, update, and delete products  
**Order Management** - View, update, and process orders  
**User Management** - Authorize admin users  
**JWT Authentication** - Secure admin login & session handling
**Fully Responsive** - Optimized for desktop & mobile

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **API Handling:** Axios
- **Authentication:** JWT
